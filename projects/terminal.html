Terminal in CSS.

A browser terminal that talks back. A quick side project to get properly comfortable with CSS animation and vanilla JavaScript — no framework, no build step.

Sector 1 — why

The itch.

Most of my day-job work lives behind an API. I wanted something small and visible where the entire point was the front end: how things move, how they respond, how it feels to type into it. A terminal is a perfect excuse — it’s all text, timing, and state.

Sector 2 — how

Built from the cursor up.

The blinking cursor, the typewriter reveal and the window chrome are pure CSS animation; the command loop, history and responses are vanilla JavaScript. No dependencies — it was the whole point to feel each piece.

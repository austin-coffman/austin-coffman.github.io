Chain.

A daily word game. Everyone gets the same set of chains; you clear one by using every letter on the board across a run of words, each starting on the letter the last one ended on.

Sector 1 — why

One rule, all day.

The pitch fits on a napkin: chain N words using every letter · each word begins where the last one ended. The pivot letter is free — you only spend letters from the shared pool to finish a word — and a chain is cleared when the pool is empty and every word is a real dictionary word.

There is no failing. A chain waits all day; reset and re-route as often as you like. Each one you finish makes the next a little bigger — more words, longer words — and the ramp accelerates once you pass the “pro” level. Stamps for the collection, a daily streak, and an emoji-grid result to share.

Sector 2 — how

Same day, same chains, no server.

Every player derives the day from the UTC day-number. That number plus the index of which chain-of-the-day you’re on seeds a Mulberry32 PRNG, and the generator lays real words down head-to-tail, then hands you the shuffled bag of exactly the letters those words need. Same day → same seed → same chains for everyone, and every chain is guaranteed solvable.

The whole dictionary ships in the client bundle so puzzles generate instantly and offline: every 4–8 letter word in ENABLE — about 79,000 of them, minus a blocklist — stored front-coded at 95 KB over the wire. Answers are drawn from a much smaller common core (~6,300 words), so a chain is always solvable with words you’d recognise even though the game accepts far more. Widening what’s accepted doesn’t make the game harder; it only makes it less wrong.

Progress — stats, streak, collection, calendar and the in-progress chain — lives in localStorage. No accounts, no backend, no environment variables; the game logic is pure and seeded, covered by Vitest, and the app deploys to Vercel as-is.

day  = floor(Date.now() / 86_400_000)
seed = seedFor(day, chainIndex)      // Mulberry32
lvl  = genLevel(seed, cfgSize(chainIndex))
// → words laid head-to-tail, then their letters, shuffled
Sector 3 — what stuck

Lessons.

  • A word game that rejects a word you know is broken. Every narrower list had a real player standing just past its edge.
  • Deterministic puzzles from a seed remove a whole category of infrastructure — there is nothing to sync when everyone can compute the same day.

Rep Zero.

A free, offline-first weight-lifting tracker that runs as an installed iPhone PWA. No accounts, no server, no network calls — every set you log stays in your device’s IndexedDB.

Sector 1 — why

Log a set in one tap.

Build your own plans, tear them up mid-workout when the rack is taken, and watch the numbers actually move. No account, no subscription, no server — and it works with no signal, because a gym basement is exactly where the signal isn’t.

Sector 2 — how

A phone app with no App Store.

Rep Zero is a Vite + React PWA. The service worker (vite-plugin-pwa) makes it installable and offline; Dexie wraps IndexedDB so every set, plan and history row lives on the device. The install gate appears whenever the app isn’t running standalone — in a browser you can look around first, but the bypass is session-only by design.

Five tabs — Today, Plans, Library, History, Progress — plus Settings, and an active workout that takes over the whole screen. The keypad sheet is the only numeric entry path: a set can never be logged without both a weight and a rep count, so bodyweight lifts take an explicit 0 rather than a blank.

The build is a folder of static files — landing page at /, app at /app/ — with the manifest served on both so Add to Home Screen works from either. HTTPS is the one hard requirement: without it the service worker won’t register and the app can’t be installed. There is no cloud copy, so Export all data (JSON) in Settings is the only backup.

Built on the Nocturne design system: one CSS file holds every token, and no colour, radius or shadow is written outside it.

Sector 3 — what stuck

Lessons.

  • Offline-first is a product decision before it is a technical one — “no server” removes accounts, billing, sync and outages in one move.
  • iOS can evict storage for apps left unused; if there is no cloud, the export button is not a feature, it is the backup.
